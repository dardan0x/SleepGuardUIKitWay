### Technical Details
- `AudioCapturePort` is main-actor (it owns the audio session and engine, like `ClipPlayer`); samples leave as an `AsyncStream<CaptureSample>`, so T4's recording actor consumes them off the main actor.
- `EngineAudioCapture`: direct input tap with no output path (the old graph fed the speaker), `.playAndRecord` + `.measurement`, a new engine per start; resumes after an interruption that allows it, an engine configuration change, or a device arriving / leaving. A format change ends the open clip.
- `CaptureProcessor` holds the tap's state behind `OSAllocatedUnfairLock(uncheckedState:)`: the one escape hatch. The layering check now matches `uncheckedState` / `withLockUnchecked` and allow-lists that file only.
- `ClipCompressor` keeps SleepGuard's codec choice (HE-AAC ~12 kbps, rate from the codec's list, AAC-LC fallback) but is one synchronous `AVAudioFile` → `AVAudioConverter` → `AVAudioFile` loop, `@concurrent`; the asset-writer version needs a dispatch queue and leaves `Sendable` warnings. A failed compression keeps the raw `.caf`.


### Completed

### Technical Details
- **Shared (0.26.0)**: content kit `LearnContent(url:)`:
  - SleepGuard's title row, then the page in a web view (`LearnWebView`), or "No content available".
  - The page loads when its URL changes; SleepGuard's reloaded on every view update.
  - Links marked `data-open-external` open through SwiftUI's `openURL`.
- **Brand value** (decided with the user; ADR 0006): `BrandConfiguration.learnURL: URL?`.
  - SleepGuard gets its URL from Remote Config, which this app doesn't have.
  - SleepGuard and Nocturne pass `nil` until a page exists, so the tab shows the empty state.
  - Lite has no Learn tab (its `tabs`).
- **`LearnFeature`** (`LearnScreen`) and **`LearnFlow`**:
  - One screen, with the nav bar hidden because the content draws its title.
  - The title stays on the navigation item for VoiceOver.
- `MainTabCoordinator` builds `LearnFlow` for `.learn`. The F1 placeholder flow and screen are gone, with their tests.
